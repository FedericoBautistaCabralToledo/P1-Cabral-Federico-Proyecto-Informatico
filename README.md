# P1-Cabral-Federico-Proyecto-Informatico

Hacer un sistema de 2 servomotores, 1 pulsador, 1 sensor de movimiento y 1 sensor de temperatura.

El sistema debe de funcionar solo mientras se presione el pulsador.

Los servomotores van a moverse entre 90° a 180° en intervalos de 3 segundos.

Cuando se detecte movimiento, los servomotores van a moverse a 0° y quedarse ahí durante 6 segundos.

Si la temperatura sube por encima de los 35° los servomotores se van a quedar quietos en la posición en la que estén.

Si el botón no está presionado los servomotores van a quedarse quietos en 45°.
